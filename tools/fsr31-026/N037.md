## Fixed mechanisms

Injected FSR passes change the Vulkan compute pipeline, descriptor bindings
and push constants. n036 did not preserve this state for subsequent native
compute dispatches whose binds were suppressed by native caches. The wrapper
now captures native state, ignores SDK-internal binds, and restores original
bindings and push writes (including partial writes and combined stage masks)
after injected work, including error paths. Unsupported descriptor extension
chains cause preflight rejection before GPU commands instead of an incomplete
restoration.

Indirect geometry now receives camera-validated raster jitter and restoration,
as in the Port. Fullscreen direct draws remain excluded. The default jitter
sign remains unchanged: the Port's negative sign is a diagnostic toggle.
No native scheduler hooks removed by n036 are reintroduced.
