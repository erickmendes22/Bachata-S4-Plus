# n045 — reject undefined and partially reused scene inputs

D39002FF, tested with n044, restores the real AMD temporal dispatch (640x360 -> 1280x720) and pre-UI composition. It ends CANCELLED_BY_USER, not with the heap panic seen in n043. The attached phone screenshot still shows cyan/white on the upper portion of the scene while the lower portion and HUD remain normal. That screenshot alone cannot locate the first corrupt GPU stage.

Two input-contract defects remain in n044: a completed color pass is accepted even with storeOp DONT_CARE/NONE, which allows its tile contents to be discarded; and a subsequent partial render pass on the same image in the same CB can rewrite the scene without a layout transition, leaving the old candidate eligible. n045 rejects unstored, offset, resolved or layered candidates, and retires a completed local scene when a new rendering instance reuses its backing image. A subsequent complete, stored camera-sized LDR pass can still establish a fresh candidate. Native rendering commands and store operations are not changed.

The GPU regression reproduces a half-cyan frame by completing a normal scene and then overwriting only its top half in a second rendering instance without a barrier. Keeping the previous rule yields 1,029,880 cyan pixels, 1,036,800 native blue pixels, and an intact 5,000-pixel HUD. The fixed rule leaves the native fallback background/HUD untouched (zero cyan). This is an input-preservation regression test, not evidence that the rejected frame runs temporal FSR. Separate valid-scene, cross-CB, depth-access, owned-UI and RunScaled tests still require real AMD dispatch.

ARM64 and software Vulkan validation passed in run 38561341881, source aa65ddcd42d7bcc53725be3327bc8e48f48aeee0. The SDK is rebuilt; core025, DEX, patches and the other runtime payload remain identical to signed n044. No RGB-format workaround or core rebuild is introduced. Device cyan elimination and long-session crash stability are not yet verified; the synthetic reproduction does not prove this is the sole cause in D39002FF.
